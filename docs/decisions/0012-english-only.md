# ADR-0012: English only for now

- Status: accepted
- Date: 2026-10-16

## Decision

The UI, labels and content are in English. Names in other languages (Musa, Moshe) exist only as search aliases.

## Consequences

GPU text with SDF atlases is enough for labels; no shaping is needed for right-to-left or complex scripts. Localization is a later epic.

## Revisit when

There is demand from non-English readers or contributors.
